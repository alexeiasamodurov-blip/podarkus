# Podarkus

Сайт для подбора подарков по анкете: 500 идей, возраст, бюджет, повод, интересы и ограничения.

Все изображения, шрифты, стили и каталог встроены в index.html. Подбор работает в браузере без ИИ и без отправки ответов на сервер. Вход и регистрация представлены демонстрационными формами; аккаунты не создаются.

Публикация: GitHub Pages, ветка main, корневая папка. Файл .nojekyll отключает обработку Jekyll.

При обновлении замените index.html и отправьте изменения в main. Серверный код и базы аккаунтов в этот репозиторий не входят.
