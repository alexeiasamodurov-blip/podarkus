# Podarkus

Сайт для подбора подарков по анкете: 500 идей, возраст, бюджет, повод, интересы и ограничения.

Все изображения, шрифты, стили и каталог встроены в index.html. Подбор работает в браузере без ИИ и без отправки ответов на сервер.

Регистрация и вход работают через Firebase Authentication: email, пароль, подтверждение адреса и восстановление пароля. Вход сохраняется только на время вкладки через browserSessionPersistence. Пароли не сохраняются приложением. История подбора и избранное к аккаунту не привязаны.

Проект Firebase: podarkus-1b631, тариф Spark. Способ входа: Email/Password. Домен сайта: alexeiasamodurov-blip.github.io. Серверная политика паролей должна требовать минимум 10 символов. Письма отправляет Firebase; применяются квоты бесплатного тарифа.

auth-config.json содержит только публичные настройки веб-приложения Firebase. Это не административный ключ и не даёт доступа к списку аккаунтов. Не добавляйте в репозиторий service-account JSON, Admin SDK credentials или выгрузки пользователей.

Код форм: src/auth-ui.js. Подключение Firebase SDK: src/auth.js. Разметка формы: src/auth-dialog.html; при её изменении обновите соответствующий диалог в index.html. Собранный браузерный файл: assets/auth.js.

Разработка: npm ci, npm test, npm run build. После изменения JS пересоберите assets/auth.js и увеличьте параметр v у ссылки на него в index.html. Сборка останавливается, если конфигурация проекта не заполнена.

Публикация: GitHub Pages, ветка main, корневая папка. Файл .nojekyll отключает обработку Jekyll.

При обновлении отправьте index.html и собранный assets/auth.js вместе с изменёнными исходниками в main. Серверный код и базы аккаунтов в этот репозиторий не входят. Старая автономная версия для флешки хранится отдельно и аккаунты не поддерживает.
